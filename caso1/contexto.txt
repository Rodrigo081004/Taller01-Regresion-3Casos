OBJETIVO
--------
Construir un simulador de precios de casas usando housing.csv (California
Housing) con regresión lineal múltiple, en Python + HTML, desplegable en
GitHub Pages (estático, sin servidor).

DATASET
-------
- housing.csv: 20,640 filas, 10 columnas (longitude, latitude,
  housing_median_age, total_rooms, total_bedrooms, population, households,
  median_income, median_house_value, ocean_proximity).
- 207 valores faltantes (total_bedrooms) -> se eliminan con dropna().
- Datos finales: 20,433 filas.
- ocean_proximity: 5 categorías (<1H OCEAN, INLAND, ISLAND, NEAR BAY,
  NEAR OCEAN). One-hot con drop_first=True (base: <1H OCEAN).

MODELO
------
- Librería: scikit-learn LinearRegression (mínimos cuadrados ordinarios).
- Predictores: 12 (8 numéricos + 4 dummies de ocean_proximity).
- Split: train_test_split(test_size=0.2, random_state=42).
- Métricas test: R² = 0.6488 | MAE = $50,413.43 | RMSE = $69,297.72.
- Intercepto: -2,299,273.76.
- Fórmula: precio = intercepto + Σ(coefᵢ × varᵢ).

ARCHIVOS CREADOS (ya subidos a GitHub, rama main)
--------------------------------------------------
1. train_model.py
   - Lee housing.csv, imputa/elimina NaN, one-hot de ocean_proximity.
   - Entrena LinearRegression y exporta model.json con:
     info, target (min/max/mean/median del precio), metrics (r2, mae,
     rmse, n, n_test), features, intercept, coefficients, ranges
     (min/max/step/default=media por variable), categorical
     (options, dummy_features, encoding solo con dummies).
   - IMPORTANTE: el encoding NO debe incluir las variables numéricas
     (bug corregido: antes sobrescribía con 0 y arruinaba la predicción).
   - Uso: python train_model.py

2. model.json (generado por train_model.py, 176 líneas)
   - Contiene coeficientes, intercepto, métricas, rangos y codificación.

3. index.html
   - Tema oscuro, tarjetas, badges de métricas (R², MAE, filas).
   - Panel izquierdo: sliders para 8 numéricas + select ocean_proximity.
   - Panel derecho: precio estimado, barra comparativa vs min/max del
     dataset, referencias (mínimo/mediana/media/máximo).
   - Sliders con fill degradado via CSS var --pct.
   - Valores por defecto = MEDIA de cada variable (no el punto medio,
     porque daba precios negativos).

4. simulador.js
   - fetch("model.json"), construye inputs desde MODEL.ranges.
   - currentVector(): inicializa todos los features en 0, llena numéricas
     desde sliders, aplica encoding[categoría] (solo dummies).
   - predict(): price = intercept + Σ coef*f; clamp a >= 0.
   - fmtUSD: formato moneda USD.
   - Carga model.json relativo (requiere servidor local o Pages,
     NO abrir como file://).

5. README.md — documentación completa (estructura, modelo, uso local,
   despliegue Pages, notas).
6. requirements.txt — pandas>=2.0, numpy>=1.24, scikit-learn>=1.3.
